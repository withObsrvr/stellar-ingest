Usage of stellar-ingest:
  -b2-endpoint string
    	B2/S3 endpoint (default "s3.us-west-004.backblazeb2.com")
  -b2-key-id string
    	B2/S3 access key ID (deprecated: set B2_KEY_ID or B2_KEY_ID_FILE)
  -b2-key-secret string
    	B2/S3 secret access key (deprecated: set B2_KEY_SECRET or B2_KEY_SECRET_FILE)
  -b2-region string
    	B2/S3 region (default "us-west-004")
  -batch-size int
    	Ledgers per extraction batch (default 1000)
  -bucket string
    	Storage bucket/path for ledger data (required)
  -chunk-concurrency int
    	Chunks to build at once when --chunk-size is set; 1 is sequential. Memory scales with this times --workers (default 1)
  -chunk-size uint
    	Maximum ledgers per sequential extract/validate/publish chunk; 0 processes the range as one chunk
  -config string
    	Path to a config file defining contexts; flags given on the command line always win
  -context string
    	Context in --config to take defaults from; empty uses the file's default-context
  -doctor
    	Check credentials, DuckDB extensions and catalog reachability, then exit without ingesting
  -ducklake
    	Push bronze Parquet to DuckLake (B2 + catalog)
  -ducklake-catalog string
    	PostgreSQL catalog DSN for DuckLake (deprecated: set DUCKLAKE_CATALOG_DSN or DUCKLAKE_CATALOG_DSN_FILE)
  -ducklake-data-path string
    	S3/B2 bucket path (e.g., s3://obsrvr-lake-testnet/)
  -ducklake-metadata-schema string
    	DuckLake metadata schema (default "bronze_meta")
  -ducklake-only-tables string
    	Comma-separated source or DuckLake table names to push; defaults to --only-tables when set
  -ducklake-schema string
    	DuckLake schema holding the physical tables (default "bronze_store")
  -ducklake-schema-sql string
    	Path to v3_bronze_schema.sql (optional)
  -ducklake-skip-tables string
    	Comma-separated source or DuckLake table names to skip during push
  -ducklake-view-schema string
    	DuckLake schema holding the presentation views (default "bronze")
  -end uint
    	End ledger sequence (required)
  -enrich-contract-balances
    	Repair missing Bronze contract balance_holder and balance fields in place
  -enrichment-chunk-size uint
    	Ledgers per contract-balance enrichment transaction (default 100000)
  -enrichment-dry-run
    	Decode and count contract-balance candidates without mutating DuckLake
  -enrichment-manifest-schema string
    	DuckLake schema for the enrichment audit manifest (default "bronze_operations")
  -enrichment-resume
    	Skip chunks already completed under the enrichment run ID (default true)
  -enrichment-run-id string
    	Durable manifest run ID (required for mutating enrichment)
  -era-id string
    	Era identifier for DuckLake partitioning (optional)
  -events string
    	Write the NDJSON event stream to this path; - for stdout. Empty emits nothing
  -files-per-partition uint
    	Files per archive partition (GCS/S3) (default 64000)
  -for string
    	Condition wait blocks on: succeeded|settled (default "succeeded")
  -ledgers-per-file uint
    	Ledgers per archive file (GCS/S3) (default 1)
  -network string
    	Network to target: mainnet|testnet|futurenet. Sets the passphrase unless --network-passphrase is given
  -network-passphrase string
    	Stellar network passphrase (default "Test SDF Network ; September 2015")
  -no-color
    	Disable ANSI colour on stderr (also honoured: NO_COLOR, a non-terminal stderr)
  -only-tables string
    	Comma-separated extractor/source/DuckLake table names to extract; empty extracts all
  -output string
    	Response format: table|json|ndjson (a directory here is deprecated)
  -output-dir string
    	Directory for Parquet output (required)
  -pg-database string
    	PostgreSQL database (default "stellar_hot")
  -pg-host string
    	PostgreSQL host for hot buffer (enables hot buffer loading)
  -pg-password string
    	PostgreSQL password (deprecated: set PG_PASSWORD or PG_PASSWORD_FILE)
  -pg-port int
    	PostgreSQL port (default 25060)
  -pg-sslmode string
    	PostgreSQL SSL mode (default "require")
  -pg-user string
    	PostgreSQL user
  -plan
    	Print which ledger ranges still need building, then exit without doing any work (requires --ducklake-catalog)
  -prefetch-buffer int
    	Decoded ledgers each worker reads ahead. Peak memory is roughly --chunk-concurrency x --workers x this x ledger size, so lower it to afford more workers on recent ledgers (default 200)
  -program-status string
    	Report OSC 7501 program status on stderr: auto|always|never (default "auto")
  -quiet
    	Suppress progress on stderr; warnings and errors are still reported
  -range-state
    	Record this ledger range as freezing/frozen in the catalog so an interrupted backfill can resume (requires --ducklake-catalog)
  -range-state-table string
    	Table holding range state (default "public.ingest_range_state")
  -start uint
    	Start ledger sequence (required)
  -storage-type string
    	Backend storage type: GCS, S3, RPC, CAPTIVE_CORE, XDR, FS (default "FS")
  -tail-ledgers uint
    	Number of recent ledgers to load into hot buffer (default 100000)
  -timeout duration
    	Abandon the run after this long, e.g. 30m or 4h; 0 means no limit
  -validate
    	Run quality validation checks after extraction
  -verbose
    	Report per-step detail and structured attributes on stderr
  -version
    	Print the build version and exit
  -workers int
    	Number of parallel workers (default <NumCPU>)
